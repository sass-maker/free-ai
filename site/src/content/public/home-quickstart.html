Quick Start

Up and running in one curl

Point your existing OpenAI SDK or curl commands at the gateway. Set model: "auto" and the gateway handles provider selection, retries, and failover.

Heads up: this aggregates free provider tiers — best-effort, no SLA. Per-IP limit is ~10 burst / ~20 rpm, each model has a daily cap, and the gateway returns 503 only when every capable model is rate-limited — rate-limit windows reset within minutes. For production throughput, pin a model and bring your own keys.

Full API reference
terminal openai sdk
# 1. Check which providers are live right now (no key needed) curl __ORIGIN__/v1/routing/status # 2. Send your first chat completion curl __ORIGIN__/v1/chat/completions \ -H "Authorization: Bearer $KEY" \ -H "Content-Type: application/json" \ -d '{ "model": "auto", "project_id": "my_project", "messages": [{ "role": "user", "content": "Hello!" }] }' # Embeddings curl __ORIGIN__/v1/embeddings \ -H "Authorization: Bearer $KEY" \ -H "Content-Type: application/json" \ -d '{ "model": "@cf/baai/bge-base-en-v1.5", "project_id": "my_project", "input": "Hello world" }'
// npm install openai (already installed if you use OpenAI SDK) import OpenAI from 'openai'; const client = new OpenAI({ baseURL: '__ORIGIN__/v1', apiKey: process.env.GATEWAY_API_KEY, }); // Chat completion — same params as OpenAI const chat = await client.chat.completions.create({ model: 'auto', project_id: 'my_project', messages: [{ role: 'user', content: 'Hello!' }], }); console.log(chat.choices[0].message.content); // Embeddings const emb = await client.embeddings.create({ model: 'gemini-embedding-001', project_id: 'my_project', input: 'Hello world', }); console.log(emb.data[0].embedding.length + ' dims');
